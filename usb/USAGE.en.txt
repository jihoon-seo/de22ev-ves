Virtual engine sound (HMG-API mod de22ev-ves 0.2.6) - for DE22EV.KOR V039 260902 only, test version

What it does
- Makes an engine-like sound live from speed, accelerator pedal and motor power (read only) and plays
  it through the cabin speakers.
- Uses the same mixing channel as the stock navigation prompts, so it plays over radio, Bluetooth and
  Android Auto music. It pauses for navigation prompts, calls and voice recognition.
- Does not touch the exterior pedestrian warning sound (VESS) or any vehicle control, and changes no
  system file.
- Off after install.
Requires: NEMESIS, HMG-API 1.0.0-beta.5 (hooks on). The mod is signed with its author's own key, so
install.txt carries a trusted-author warning; the install goes ahead.

USB stick
- Unzip and put NEMESIS.data, NEMESIS.sh and the VES_MOD and VES folders at the top of the USB stick
  (the car check finds the stick only when the VES folder exists; an empty one is fine).
- The first line of VES_MOD/MODE.txt: install (default) / status / uninstall

Steps
1. Install: start the car, wait about a minute after boot, insert the stick and choose Yes.
   STATUS.txt: INSTALLED_RESTART_THE_CAR.
2. Turn the car off, lock it, wait 5 minutes or more, then start it (the menu tile, the star key action
   and the split-screen widget attach at this boot).
3. Open "엔진 사운드" (Engine sound) from the all-apps menu > "차량 점검" (car check) with the stick in,
   and follow the screens (test tones, navigation prompt overlap, chimes, then a short drive recording).
   Everything but the drive recording is done parked. Don't touch the screen while driving.
4. Send the VES folder (probe-... folders) from the stick. If something is wrong, set MODE.txt to
   status, insert the stick, choose Yes and send the VES_MOD_* folder too.

Sound: the synth, inline-4 turbo, V6, V8, inline-6, or user slots 1-8. Behaviour by default "like an
ICE car" (idles in P/N/D when Ready, engine braking when coasting, optional exhaust pops).
Under navigation prompts and alerts the engine sound plays on at 30 % (or pauses, a setting); the
stock navigation's voice takes the channel, so it pauses for that and is back 0.5 s later. Calls and
voice recognition always pause it. The experimental setting "voice" plays on quietly under the
navigation's voice too, but it may cut prompts (if one seems cut, it gives up for the rest of the drive).
Own sound packs: put pack.txt and WAV loops (22050 Hz mono 16-bit) in VES/packs/<folder>/ on the
stick and use "USB에서 소리 팩 가져오기" in the app (format: README on GitHub).
Settings: the app, the split-screen widget, the star key action, or HMG-API's Mods tab (there,
press "Save settings" at the bottom: leaving the screen without it drops the change; Apply
changes isn't needed).
Update: install the new version the same way; settings are kept. STATUS.txt UPDATED_IN_USE_NOW means
it is in use at once (app and service replaced on the spot), no car restart needed.

Remove (MODE.txt = uninstall): turns the mod off and removes it and its app. Stock behaviour from the
next boot.
