가상 엔진 사운드 (HMG-API 모드 de22ev-ves 0.2.7) - DE22EV.KOR V039 260902 전용, 시험판

하는 일
- 속도, 가속 페달, 모터 출력(읽기만 함)으로 엔진 소리를 실시간으로 만들어 실내 스피커로 냅니다.
- 순정 내비 안내음과 같은 섞임 채널을 써서 라디오/블루투스/Android Auto 음악 위에 섞어 냅니다.
  내비 안내, 전화, 음성인식이 나오면 잠시 멈췄다가 끝나면 다시 납니다.
- 차 밖 보행자 경고음(VESS)과 차량 제어는 건드리지 않습니다. 시스템 파일도 바꾸지 않습니다.
- 설치 직후에는 꺼져 있습니다.
필요: NEMESIS, HMG-API 1.0.0-beta.5 (훅 켜짐).
직접 만든 키로 서명된 모드라 install.txt 에 trusted author 경고가 남습니다(설치는 정상 진행).

USB 준비
- ZIP을 풀어 NEMESIS.data, NEMESIS.sh, VES_MOD, VES 폴더를 USB 최상위에 놓습니다.
  (VES 폴더가 있어야 차량 점검이 USB를 찾습니다. 없으면 빈 VES 폴더를 만드세요.)
  (다른 키트의 NEMESIS.sh/NEMESIS.data 와 이름이 같으니 바꿔치기됩니다.)
- VES_MOD/MODE.txt 첫 줄: install(기본) / status / uninstall

순서
업데이트: 같은 방법으로 새 버전을 설치하면 설정은 그대로 두고 바꿉니다. STATUS.txt 가 UPDATED_IN_USE_NOW 이면
시동을 다시 걸 필요 없이 바로 적용됩니다(앱과 서비스를 그 자리에서 바꿈).

1. 설치: 시동 ON, 부팅 후 1분쯤 지나 USB를 꽂고 Yes. STATUS.txt: INSTALLED_RESTART_THE_CAR.
2. 시동을 끄고 문을 잠근 뒤 5분 이상 지나 다시 켭니다(메뉴 타일, ★ 버튼, 분할 화면 위젯이 이때 붙습니다).
3. 전체 메뉴의 "엔진 사운드" 앱 > "차량 점검 (주차 상태에서)"을 엽니다. USB를 꽂은 채로
   화면 안내대로 진행합니다(시험음, 내비 안내 겹침, 경고음, 마지막에 짧은 주행 기록).
   주행 기록 단계 말고는 모두 주차(P) 상태에서 합니다. 주행 중에는 화면을 만지지 마세요.
4. 점검이 끝나면 USB의 VES 폴더(probe-… 폴더)를 보내 주세요.
   문제가 있으면 MODE.txt 를 status 로 바꿔 USB를 꽂고 Yes, VES_MOD_* 폴더도 보내 주세요.

조작
- 엔진 사운드 앱: 켜기/끄기, 볼륨 -/+, 소리 종류, 정차·회생 동작, 공회전/회생음 크기, 페달 반응, 고속 줄임,
  고속 보강(40 km/h부터 110 km/h까지 차츰 키움: 끔/약하게/보통/강하게, 기본 강하게).
- 볼륨은 0.2.7부터 같은 값에서 0.2.6보다 6 dB 큽니다.
- 분할 화면 위젯 "엔진 사운드": 켜기/끄기, 볼륨 -/+.
- ★ 버튼: 설정 > 버튼 설정에서 "엔진 사운드 켜기/끄기"를 고르면 버튼 한 번으로 켜고 끕니다.
- 엔진 소리: 합성음, 4기통 터보, V6, V8, 직렬 6기통, 사용자 칸 1-8. 동작은 기본 "내연기관처럼"
  (Ready면 P/N/D 공회전, 발을 떼면 엔진 브레이크 소리, 배기 팝 설정).
- 안내 음성·알림음이 나오면 엔진 소리를 30%로 줄여 계속 냅니다(설정에서 "멈춤"으로 바꿀 수 있음).
  순정 내비 음성은 차가 채널을 가져가므로 그동안 멈추고, 끝나면 0.5초 뒤 다시 납니다. 전화와 음성인식
  때는 항상 멈춥니다. 실험 기능 "안내 음성 중에도 작게"는 내비 음성 중에도 작게 내지만 안내가 끊길 수
  있습니다(끊긴 것 같으면 그 주행이 끝날 때까지 쓰지 않음).
- 직접 만든 소리 팩: USB의 VES/packs/<폴더>/ 에 pack.txt 와 WAV 루프(22050 Hz 모노 16비트)를 두고
  앱의 "USB에서 소리 팩 가져오기"로 사용자 칸에 넣습니다. 형식은 GitHub의 README 참고.
- HMG-API 앱의 Mods 탭에서도 같은 설정을 바꿀 수 있습니다. 거기서는 바꾼 뒤 맨 아래 "Save settings"를
  눌러야 저장됩니다(누르지 않고 다른 화면으로 가면 원래 값으로 돌아감). Apply changes 는 필요 없습니다.

제거 (MODE.txt = uninstall)
- 모드를 끄고 지웁니다(앱도 지워짐). 다음 부팅부터 순정 동작입니다.
